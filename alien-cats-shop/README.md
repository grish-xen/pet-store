# PAWpi

Учебный React-макет зоомагазина в стиле инопланетных котиков.

## Запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Для локального просмотра сборки: `npm run preview`.

## Структура

- `src/components` - повторяющиеся компоненты: шапка, футер, карточка товара, кнопки.
- `src/pages` - страницы сайта: главная, каталог, товар, корзина, оформление, профиль, акции, бренды, отзывы и другие.
- `src/data` - данные для товаров, категорий, акций и навигации.
- `src/assets` - шрифты, иконки и изображения.
- `public` - файлы, которые должны лежать напрямую в браузере, например favicon.

Отчёт, задание и мудборд находятся в [docs](../docs). Общее описание проекта и инструкции для репозитория находятся в [README](../README.md).
