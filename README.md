# PAWpi

Учебный проект интернет-магазина товаров для питомцев с оформлением в стиле инопланетных котиков.

Автор: Гришина Ксения Дмитриевна.

## Возможности

Каталог с поиском и фильтрами, быстрый просмотр и страницы товаров, избранное, корзина с выбором товаров и расчётом доставки, оформление заказа и профиль с заказами. Также доступны страницы новинок, акций, брендов, отзывов, компании и контактов.

Проект представляет собой клиентский прототип на React и Vite. Данные товаров хранятся в исходниках; настоящие платежи и серверная обработка заказов не подключены.

## Запуск

Требуется Node.js 22 LTS и npm.

```bash
cd alien-cats-shop
npm ci
npm run dev
```

Адрес сайта появится в терминале после запуска Vite.

## Сборка

```bash
cd alien-cats-shop
npm run build
npm run preview
```

Готовая сборка создаётся в `alien-cats-shop/dist`.

## Структура

```text
alien-cats-shop/
  public/                Статические файлы
  src/
    assets/              Изображения, иконки и шрифты
    components/          Общие компоненты интерфейса
    data/                Товары, категории, акции и навигация
    pages/               Страницы магазина
    App.jsx              Состояние приложения и переходы
    styles.css           Стили
  package.json           Зависимости и команды
  package-lock.json      Зафиксированные версии зависимостей
docs/                    Отчёт, задание и мудборд
```

Локальный архив `_legacy-static`, зависимости, сборка, временные файлы и настройки среды исключены из Git. `package-lock.json` следует хранить в репозитории.

## Материалы

Документы учебной практики находятся в `docs`. Лицензия используемого шрифта Chiron GoRound TC находится в `alien-cats-shop/src/assets/fonts/OFL.txt`.
